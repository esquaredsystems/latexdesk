# LaTeX Desk template library

`templates.json` is the catalog behind **Create from Template** in LaTeX Desk. The extension
downloads it from this folder on GitHub (the `main` branch) when the template gallery opens, and
downloads a template's ZIP file from here when the user creates a project from it. A change
reaches users as soon as it is pushed to `main`; no new release of the extension is needed.

This folder is not packaged into the extension.

## Catalog format

```json
{
  "version": 1,
  "updated": "2026-10-25",
  "templates": [
    {
      "id": "ieee-conference",
      "name": "IEEE Conference Paper",
      "type": "conference",
      "publisher": "IEEE",
      "description": "Two-column conference paper with the IEEEtran class.",
      "tags": ["engineering", "computer science"],
      "filename": "ieee-conference.zip",
      "main": "main.tex",
      "engine": "pdflatex",
      "bibliography": "bibtex",
      "requires": ["IEEEtran.cls"],
      "license": "MIT",
      "source": "https://www.ieee.org/conferences/publishing/templates.html"
    }
  ]
}
```

| Field | Required | Meaning |
| --- | --- | --- |
| `id` | yes | Unique; lowercase letters, digits and `-`. Also the default project folder name. |
| `name` | yes | Name shown in the gallery. |
| `type` | yes | `journal`, `conference`, `thesis`, `book`, `report`, `article`, `presentation`, `poster`, `cv`, `letter` or `other`. |
| `publisher` | no | Publisher, society or conference. Searched. |
| `description` | no | One or two sentences. Searched. |
| `tags` | no | Subjects and keywords. Searched. |
| `filename` | no | The ZIP in this folder (or an absolute `https` address). Without it, the gallery offers "Get from publisher" and "Create from a downloaded ZIP". |
| `main` | no | Root document inside the ZIP. Otherwise LaTeX Desk looks for it. |
| `engine` | no | `pdflatex`, `xelatex` or `lualatex`. |
| `bibliography` | no | `bibtex`, `biber` or `none`. |
| `requires` | no | Class and package files the template expects from the TeX distribution. LaTeX Desk checks them with `kpsewhich` after creating the project. |
| `license` | no | Licence of the ZIP's contents. |
| `source` | no | The official page of the template. |

**Order matters:** templates are listed from most used to least used, and the gallery's "Most
used" sort follows this order. Unknown fields are ignored, so new fields can be added without
breaking older versions of the extension.

## ZIP files

- Put the project's files at the top of the ZIP, or inside one folder (the folder is removed when
  the project is created). `__MACOSX` folders and `._*` files are ignored.
- Keep a ZIP under 50 MB and 2,000 files.
- Add a publisher's kit only when its licence allows redistribution. Otherwise leave out
  `filename` and point `source` to the publisher's page.

The starters (every ZIP licensed MIT in the catalog) contain only a `main.tex`, a sample
`references.bib` and a placeholder figure, written for this library; the document class comes from
the user's TeX distribution. They are generated by `scripts/template-starters/build.py`, which also
compiles each one:

```sh
python3 scripts/template-starters/build.py templates   # rebuilds every starter ZIP into templates/
```

## Checking

```sh
python3 scripts/check-templates.py             # catalog fields, ids, ZIP files, main files
python3 scripts/check-templates.py --compile   # also builds every ZIP with latexmk
```

Run the check before committing a change to the catalog.
